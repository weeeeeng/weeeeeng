## Current Projects｜目前專案

### RV32I Processor

**English**

A basic RV32I processor implemented in Verilog for learning processor architecture, RTL design, and functional verification.

**中文**

使用 Verilog 實作的基礎 RV32I 處理器，用來學習處理器架構、RTL 設計與功能驗證。

- Repository：[rv32i_processor](https://github.com/weeeeeng/rv32i_processor)
- Language：Verilog
- Tools：Intel Quartus Prime, ModelSim

### FPGA Attention Accelerator

**English**

An FPGA-based hardware acceleration project focusing on Self-Attention and FlashAttention-related computations.

**中文**

以 FPGA 實作 Self-Attention 與 FlashAttention 相關運算的硬體加速專案。

- Target platform：Intel Cyclone V SoC
- Topics：Matrix multiplication, online softmax, streaming architecture
- Interfaces：Avalon-MM, Avalon-ST
